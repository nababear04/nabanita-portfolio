## 🛠️ Tech Stack

- **Core**: HTML5, Vanilla JavaScript (ES Modules)
- **Styling**: Vanilla CSS (Custom Design System, Glassmorphism, CSS 3D Transforms)
- **3D & Visuals**: Three.js, Canvas Confetti
- **Audio**: Web Audio API (Synthesized ambient dream lo-fi & UI chimes)
- **Bundler & Dev Server**: Vite

## 🚀 Running Locally

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start development server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```
